# Ahmadverse

My personal portfolio: the site I use to show client work and take on freelance projects.

**Live:** [ahmadverse.vercel.app](https://ahmadverse.vercel.app/)

## What's in it

- Animated home page with smooth scrolling, built with GSAP, Motion and Lenis
- Work section with a filterable project list and a full case study page for each project
- About page with an FAQ
- Contact form that sends through Resend, with validation by Zod
- `sitemap` and `robots` routes for SEO

## Stack

Next.js · React · TypeScript · Tailwind CSS · GSAP · Motion · Lenis · Resend · Zod

## Run it locally

```bash
git clone https://github.com/ahmadtahir1399/ahmadverse-portfolio.git
cd ahmadverse-portfolio
npm install
npm run dev
```

The contact form needs a Resend API key in `.env.local`. Everything else runs without any setup.
